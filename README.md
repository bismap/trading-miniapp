# Торговля — Telegram Mini App (MVP)

Быстрый прототип: дашборд + закрытие шагов + пополнения.  
Данные хранятся в **Telegram CloudStorage** (привязаны к твоему аккаунту).

---

## 1. Создай бота (точные команды)

1. Открой Telegram → найди **@BotFather**
2. Отправь:
   ```
   /newbot
   ```
3. Имя бота (как будет отображаться), например:
   ```
   Моя Торговля
   ```
4. Username бота (должен заканчиваться на `bot`), например:
   ```
   my_trading_plan_bot
   ```
5. BotFather пришлёт **токен** (сохрани его, но для этого MVP токен почти не нужен).

---

## 2. Задеплой Mini App (скопировал → вставил)

Самый простой способ — **Netlify Drop** или **Cloudflare Pages** / **Vercel**.

### Вариант A — Netlify Drop (самый простой, без аккаунта почти)

1. Открой: https://app.netlify.com/drop
2. Перетащи **всю папку** `trading-miniapp` (внутри должны быть `index.html`, `styles.css`, `app.js`)
3. Получишь ссылку вида:
   ```
   https://random-name-123.netlify.app
   ```
4. Скопируй эту ссылку.

### Вариант B — Cloudflare Pages / Vercel
- Залей папку как статический сайт
- Главная страница должна открывать `index.html`

---

## 3. Привяжи Mini App к боту

1. Снова открой **@BotFather**
2. Отправь:
   ```
   /mybots
   ```
3. Выбери своего бота
4. Нажми **Bot Settings** → **Menu Button**
5. Выбери **Configure menu button**
6. Нажми **Edit menu button URL** (или Configure)
7. Вставь ссылку на свой сайт, например:
   ```
   https://random-name-123.netlify.app
   ```
8. Title (текст кнопки), например:
   ```
   Открыть план
   ```

Готово. Теперь у бота внизу слева появится кнопка меню → по нажатию откроется Mini App.

---

## 4. Как пользоваться в Mini App

- **Дашборд** — текущий капитал, прибыль, % роста, прогресс до цели
- **Параметры** — меняй стартовый капитал, % на шаг, цель → «Сохранить параметры»
- **Следующий шаг** — можно указать пополнение и нажать «Закрыть шаг»
- **Список шагов** — фильтры Все / Закрытые / План
- Данные сохраняются автоматически в Telegram

---

## 5. Проверка без Telegram

Можно просто открыть `index.html` в браузере — будет работать через `localStorage`.  
В Telegram данные пойдут в CloudStorage.

---

## Что умеет MVP

✅ Дашборд (капитал, прибыль, рост, прогресс)  
✅ Редактируемые параметры (% , старт, цель)  
✅ Закрытие шагов с датой  
✅ Пополнения  
✅ Список шагов с фильтрами  
✅ Хранение в Telegram CloudStorage
